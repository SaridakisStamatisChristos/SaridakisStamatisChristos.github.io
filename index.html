Research focus

Execution correctness

A capable model does not automatically produce a reliable autonomous system. The surrounding runtime still has to decide whether an action is authorized, whether required invariants hold, whether execution is safe, whether resulting state can be verified, and how the system should recover after partial failure.

My work centers on the boundary between model intelligence and execution authority.
